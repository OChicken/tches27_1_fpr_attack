* Cycle Usage

We shall measure trace segment-wise. It's calculated by

: #CONCATENATE = TOTAL_SAMPLES // HUSKY_MAX_SAMPLES + 1
: TOTAL_SAMPLES = TOTAL_CYCLES * PPC

To measure =TOTAL_CYCLES=, wrap =HAL_CYCCNT= around the interested parts.
